# Imperial Astromap

Готический редактор звёздного сектора во вселенной Warhammer 40,000.

## Возможности

- Карта сектора со звёздными системами и фракционными цветами.
- Двойной щелчок по системе открывает орбитальную схему.
- Редактирование названия, фракции, цвета и описания системы.
- Добавление планет с типами миров, включая мир-гробницу некронов и орочий мир.
- Карта поверхности планеты с добавлением и редактированием точек интереса.
- Локальное сохранение в браузере, импорт и экспорт JSON.

## Запуск

Откройте `index.html` в современном браузере. Для публикации через GitHub Pages включите Pages в настройках репозитория и выберите ветку `main`, папку `/ (root)`.

Данные хранятся локально в браузере. Для переноса на другое устройство используйте экспорт JSON.
